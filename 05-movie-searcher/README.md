# 🎬 Movie Search App

A Junior-level React project: a simple and responsive movie search application powered by the OMDb API.

## 🔍 Features

- Search for movies using a title input and search button

- Display movie results in a responsive grid

- Show movie title, year, and poster

- Automatically fetch results while typing (with debounce)

- Prevent duplicate searches

- Optional alphabetical sorting with a checkbox

## 🚀 Getting Started

- Get your free API key from OMDb API

- Replace [yourkey] in the API URL:
  `http://www.omdbapi.com/?apikey=[yourkey]&s=`

## 🛠 Tech Stack

- React (Junior-level project)

- Fetch API for HTTP requests

- HTML/CSS for styling
